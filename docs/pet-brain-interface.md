# LX-PET/1: the pet-brain interface

A Lingxi pet's mind is a TapeOut circuit on X Layer. This page is the interface any project can target: build a brain
that reads these pins and writes these answers, and it can live in Lingxi's world, be checked by Lingxi's tools, or be
REF'd into another circuit. The catalogue of every Lingxi circuit, with test vectors checked on X Layer, is
[`apps/web/public/circuits.json`](../apps/web/public/circuits.json); the page that runs them in a browser with none of
Lingxi's code is [`circuits.html`](https://lingxi.knole.me/circuits.html).

## Where the circuits are

- Chain: X Layer mainnet (chain id 196). Public RPCs: `https://rpc.xlayer.tech`, `https://xlayerrpc.okx.com` (both answer
  browsers from any origin; a JSON-RPC batch may hold at most 19 calls).
- Processor: `0xf70d324Da8C1C4Cb0dE3FF147E53E7E9db543c4e`, a TapeOut processor registered with TapeOut's factory.
- Calls, both free views:
  - `eval(uint256 id, bytes inputs) returns (bytes outputs)` for a circuit with no memory (the rule circuits);
  - `step(uint256 id, bytes state, bytes inputs) returns (bytes newState, bytes outputs)` for a brain.

## Packing

Inputs, outputs and memory are packed the same way: little-endian bytes, bit 0 of the word in bit 0 of the first byte,
`ceil(n / 8)` bytes for `n` pins. Every Lingxi circuit has 16 input pins (2 bytes) and 8 output pins (1 byte).

## The 16 input pins

| pins | field | values |
|---|---|---|
| 0-1 | hunger | 0 full · 1 peckish · 2 hungry · 3 starving |
| 2-3 | joy | 0 sad · 1 low · 2 happy · 3 joyful |
| 4-5 | energy | 0 exhausted · 1 tired · 2 fine · 3 rested |
| 6-7 | clean | 0 filthy · 1 dusty · 2 tidy · 3 spotless |
| 8-9 | time | 0 night · 1 morning · 2 day · 3 evening |
| 10-12 | action | 0 none · 1 feed · 2 play · 3 clean · 4 lightsOff · 5 pet · 6 medicine · 7 talk |
| 13-14 | event | 0 none · 1 friend · 2 toy · 3 scary |
| 15 | owner | 0 away · 1 here |

## The 8 output pins

| pins | field | values |
|---|---|---|
| 0-2 | want | 0 idle · 1 eat · 2 play · 3 sleep · 4 explore · 5 sulk · 6 cuddle · 7 share |
| 3-4 | mood | 0 grumpy · 1 calm · 2 happy · 3 excited |
| 5-7 | nudge | 0 none, else one step of trait drift: 1 brave · 2 curious · 3 greedy · 4 calm · 5 playful · 6 gentle · 7 shy |

## Memory

A brain's memory is LATCH bits after the gates, carried between beats by `step`. Each program declares its fields in
order, and their bits follow that order. The starter brains declare: `trust` (a 3-bit counter), `likesToys` (a flag),
`scared` (a flag) and `awake` (a 3-bit timer that counts beats since the last sleep and stops at 7): 8 bits. A fresh pet
starts from all zeros. One beat is one minute of a pet's life.

## Rule circuits

A rule circuit answers one question of the game's rules (what a search finds, how a gift moves trust, what a skill does)
from the low `inBits` of its 16 input pins, as one byte; the pins above `inBits` are ignored. Each one's meaning, input
width and every documented answer are in the catalogue, and the game checks on every load that the rules it runs are
byte for byte the circuits on chain.

## Using one in your own circuit

A TapeOut netlist can REF any registered processor's circuit; REF'd gates burn no transistors. The worked example
[`scripts/ref-example.mts`](../scripts/ref-example.mts) builds a circuit that REFs Lingxi's trust rule (circuit #8) and
passes its answer through, and proves it gives the trust rule's answer on every input with the circuit read from X
Layer. Copy it and put your own gates between the REF and the outputs.

## Checking an answer

For a rule, `eval(id, inputs)` must give the catalogue's answer for that input; for a brain, `step(id, zero state,
inputs)` must give the catalogue's outputs and next state. The catalogue is regenerated by
`npx tsx scripts/circuit-catalogue.mts`, which refuses to write it unless every vector agrees with X Layer and every
netlist on chain hashes to the one written (`--check` checks the published file the same way).
