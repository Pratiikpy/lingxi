# Art the game does not use

The source art set's files that nothing in Lingxi references, moved here from `public/` (P3) so the live site and every
build stop carrying them (about 8 MB) while they stay in the repo for any feature that wants one later. Each was proven
unused before it moved: no file in the repository names it by path, by file name or by stem, and the on-chain (DeWEB)
copy, which drops every art file nothing names, had already run without them. To use one, move it back under
`public/art/` at the same path.
